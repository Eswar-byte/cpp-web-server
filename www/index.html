cws 0.2

A static HTTP/1.1 server in C++17. No dependencies, no framework, no blocking I/O anywhere on the request path.

How a request is served

  1. The listening socket is edge-triggered; every event loop drains accept() until EAGAIN.
  2. The request head is accumulated across reads until CRLFCRLF — never assumed to arrive in one segment.
  3. The path is looked up in a map built at startup, so traversal has nothing to escape into.
  4. The response is a writev() of three pointers: precomputed header, cached Date line, resident body. Zero allocations.
  5. Short writes leave the tail pending; the write filter re-fires when the send buffer drains.

Try it

curl -i http://localhost:8080/
curl -i http://localhost:8080/nope          # 404
curl -i -X POST http://localhost:8080/      # 405
curl -i --path-as-is http://localhost:8080/../../etc/passwd   # 400
